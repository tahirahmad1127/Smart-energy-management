# Voltify — IoT Electricity Monitoring Platform

Final Year Project: a Flutter app paired with IoT hardware for real-time electricity monitoring across residential and commercial sites, with alerts to reduce waste and remote home automation.

## Key features

- Real-time power consumption monitoring from IoT sensors
- Usage alerts and thresholds to reduce electricity waste
- Remote control of home electricals from the mobile app
- Historical usage graphs and reports
- Firebase real-time sync between hardware and app

## Tech stack

Flutter · Dart · Firebase · IoT hardware · C++ (firmware) · Python (backend)

## Getting started

```bash
flutter pub get
flutter run
```
